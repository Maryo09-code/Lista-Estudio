📚 Organizador de Estudio

Aplicación web diseñada para organizar las asignaturas y gestionar el progreso del estudio de forma sencilla, visual e intuitiva.

✨ Características

Organización por asignaturas: Cada asignatura contiene sus correspondientes temas.

Lista de tareas: Marca cada tema cuando hayas terminado de estudiarlo.

Seguimiento del progreso: Los temas completados aparecen tachados.

Acceso directo: Haz clic en un tema para abrir su material de estudio en una nueva pestaña.

Guardado automático: Conserva los temas completados aunque cierres el navegador.

Diseño adaptable: Compatible con ordenadores, tablets y móviles.

🎯 Objetivo

Facilitar la planificación del estudio, mantener las asignaturas organizadas y controlar de un vistazo los temas pendientes y completados.
